# ✉️ Firma de Correo Electrónico & Mini Portfolio

Bienvenido a mi primer proyecto práctico de maquetación web. Este repositorio contiene el código de una firma de correo electrónico personalizada y una estructura inicial para un portfolio, creados como toma de contacto antes de comenzar mi formación oficial en el ciclo de Desarrollo de Aplicaciones Web (DAW).

## 🚀 Sobre el Proyecto

El objetivo principal de este ejercicio fue interiorizar la estructura de **HTML** y dar los primeros pasos con **CSS**, asegurándome de separar el contenido de la presentación visual. 

### Características
* **Firma de Email:** Maquetación estructurada con logotipos, iconos de redes sociales y enlaces.
* **CSS Externo:** Práctica de buenas costumbres enlazando una hoja de estilos independiente (`emailSignature.css`).
* **Mini Portfolio:** Estructura de directorios preparada para escalar e incluir elementos multimedia en el futuro.

## 🛠️ Tecnologías Utilizadas

* HTML5
* CSS3

## 🧠 Lo que he aprendido con este proyecto

* Estructuración semántica básica de un documento HTML.
* Enlazado y aplicación de hojas de estilo externas.
* Gestión de rutas relativas para la inserción de imágenes y recursos.
* Uso de etiquetas de anclaje (`<a>`) para la navegación externa.

## 📂 Estructura del Repositorio

- `/emailSignature/` - Archivos principales de la firma (HTML y CSS).
- `/imagenes/` - Recursos gráficos (logos e iconos de RRSS).
- `/portfolio/` - Directorio destinado a futuros trabajos y pruebas multimedia.
